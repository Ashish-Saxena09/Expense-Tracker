# Expense Tracker

A simple expense tracker made with React and Redux Toolkit.

## Features

* Add an expense
* Enter expense name and amount
* Delete an expense
* Clear all expenses
* Calculate total expenses
* Search functionality

## Technologies Used

* React
* Redux Toolkit
* React Redux
* JavaScript
* CSS

## How to Run

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Project

This project was made for practicing React and Redux Toolkit.
